# JavaScript Array Fundamentals

Welcome to my first collection of projects focusing entirely on **JavaScript Arrays**. This repository contains three distinct mini-projects designed to practice array manipulation, array methods, loops, and conditional logic.

## 📂 Projects Included

### 1. Music Playlist Manager (Easy)
A simple application to add, view, and delete songs from a playlist array.
* **Key Concepts:** `push()`, `splice()`, `forEach()`

### 2. Camp Backpack Control System (Normal)
A checklist script that compares a mandatory camping gear array against the items currently in a backpack, returning a status report and a list of missing items.
* **Key Concepts:** `includes()`, array comparison, string templates, conditional logic.

### 3. Boutique Hotel Room Management System (Hard)
A room booking system that tracks the status of 10 rooms. It allows the system to reserve a room, dynamically find the first available empty room, and list the current status of all rooms.
* **Key Concepts:** `for` loops, index tracking, array state mutation, `return` statements.

## 🚀 Technologies Used
* Vanilla JavaScript (ES6+)
* HTML5

## 💡 How to Run
1. Clone this repository to your local machine.
2. Navigate to any of the three project folders (`projectEasy`, `projectNormal`, or `projectHard`).
3. Open the `index.html` file in your web browser.
4. Open the Developer Tools (usually `F12` or `Right Click -> Inspect`) and navigate to the **Console** tab to see the array operations and functions in action.
